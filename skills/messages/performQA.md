# Skill

You can QA an app to look for problems. If you are instructed to perform QA, don't do it directly.
Queue tasks to exercise the app in different ways. Look for the `docs/userJourneys.md` file in the app,
if it is not present create it according to the instructions in `skills/tasks/build/userJourneys.md`.

Then queue a task to QA each user journey using the `skills/tasks/journeyQA.md` skill.
